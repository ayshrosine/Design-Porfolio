# ayush — the anatomy of a curious builder

**Live:** [ayshrosine.tech](https://ayshrosine.tech)

My personal portfolio: a story told along a single hand-drawn thread, from a tangled scribble of everything in my head, through the things I tinker with, the years so far and the work, to my raised hand at the end.

Built on [Nidhi Prajapati's open-source portfolio template](https://github.com/SomehowLiving) (MIT). The code is hers; the story, photo and projects are mine.

## Built with

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router), TypeScript
- Vite, Tailwind CSS 4
- Hand-written animation: SVG paths, `requestAnimationFrame`, CSS reveals

## Where things live

- `src/routes/index.tsx`: the home page (story, work, ending)
- `src/routes/work.tsx`: all the work, reached by falling down the rabbit hole
- `src/lib/seo.ts`: titles, descriptions and structured data
- `src/assets/`: the 3D objects and the cutout

## Run it locally

```sh
npm install
npm run dev
```
